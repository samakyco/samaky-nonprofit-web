# Samaky for Nonprofits (demo)

A clickable demo of the Samaky volunteer coordinator dashboard, using sample data for the fictional nonprofit page "Eastside Senior Commons".

- Live site: https://nonprofit.samaky.co (once DNS is set up)
- Visit the site root. `index.html` is a frame that shows each screen, so the address bar always stays on the bare domain. The Home screen itself is `Home.html`.
- All names, numbers and organizations shown are sample data.
